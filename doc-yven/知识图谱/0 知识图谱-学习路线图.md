```
    ↓
阶段五：行业实战（持续）
    │
    ├── 选择垂直领域
    ├── 构建领域知识图谱

```

## 推荐学习顺序

### 第一周：建立认知
1. 阅读《知识图谱-基础概念与入门指南》
2. 安装 Neo4j Desktop，跟着官方教程操作
3. 用 Cypher 创建包含10个节点、15条关系的小图谱

### 第二周：深入语义网
1. 阅读《知识图谱-语义网与本体建模》
2. 安装 Protégé，设计一个简单的领域本体
3. 用 Turtle 格式手写 RDF 数据

### 第三周：知识抽取
1. 阅读《知识图谱-构建技术详解》
2. 用 spaCy 或 HanLP 做 NER 实验
3. 尝试用 GPT-4 API 抽取文本中的实体和关系

### 第四周：图数据库
1. 阅读《知识图谱-图数据库与存储技术》
2. 对比 Neo4j 和 NebulaGraph 的基本操作
3. 将之前抽取的知识导入图数据库

### 第五周：表示学习
1. 阅读《知识图谱-表示学习与知识推理》
2. 用 OpenKE 或自研代码实现 TransE
3. 在 FB15k 数据集上训练并评估

### 第六周：GraphRAG
1. 阅读《知识图谱-大模型与GraphRAG技术》
2. 部署 LightRAG，导入自己的文档
3. 对比传统 RAG 和 GraphRAG 的效果

### 第七周起：项目实战
1. 阅读《知识图谱-应用场景与行业实践》
2. 选择一个感兴趣的领域（如电影、书籍、医疗）
3. 从零构建一个完整的知识图谱应用
