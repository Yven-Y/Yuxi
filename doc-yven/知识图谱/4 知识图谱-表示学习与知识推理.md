> 整理日期：2026-05-28

## 一、知识图谱表示学习（Knowledge Graph Embedding）

### 1.1 为什么需要表示学习

知识图谱中的实体和关系是离散的符号，无法直接用于机器学习模型。表示学习将符号映射为**低维稠密向量**，使机器能够：
- 计算实体/关系的相似度
- 发现隐含的模式和关联
- 支持下游任务（推理、推荐、问答）

### 1.2 基本形式

给定三元组 (h, r, t)，学习：
- **实体嵌入**：h, t ∈ R^d
- **关系嵌入**：r ∈ R^d

通过定义评分函数 f(h, r, t) 衡量三元组的合理性。

## 二、翻译模型系列

### 2.1 TransE（2013）

**核心思想**：关系 r 作为从头实体 h 到尾实体 t 的翻译向量。

```
目标：h + r ≈ t

评分函数：f(h, r, t) = -||h + r - t||

损失函数（Margin Ranking Loss）：
L = Σ max(0, γ + f(h, r, t) - f(h', r, t'))

其中 (h', r, t') 是负样本（替换头或尾实体）
```

**优点**：简单、参数少、训练快
**缺点**：难以处理 1对N、N对1、N对N 关系

**示例**：
```
(中国, 首都, 北京)
→ 中国的向量 + 首都的向量 ≈ 北京的向量

(法国, 首都, 巴黎)
→ 法国的向量 + 首都的向量 ≈ 巴黎的向量
```

### 2.2 TransH（2014）

**核心思想**：关系定义在超平面上，实体先投影到关系超平面。

```
h⊥ = h - w_r^T h · w_r
t⊥ = t - w_r^T t · w_r

目标：h⊥ + r ≈ t⊥

评分函数：f(h, r, t) = -||h⊥ + r - t⊥||
```

**改进**：一个实体在不同关系中有不同表示

### 2.3 TransR（2015）

**核心思想**：每个关系有独立的语义空间，通过投影矩阵转换。

```
h_r = M_r · h
t_r = M_r · t

目标：h_r + r ≈ t_r

评分函数：f(h, r, t) = -||h_r + r - t_r||
```

**改进**：更精细的关系建模

### 2.4 TransD（2015）

**核心思想**：动态投影矩阵，由实体和关系共同决定。

```
M_rh = r_p · h_p^T + I
M_rt = r_p · t_p^T + I
```

### 2.5 翻译模型对比

| 模型 | 核心改进 | 参数量 | 适用场景 |
|------|---------|--------|---------|
| TransE | 基础翻译 | 少 | 简单关系 |
| TransH | 超平面投影 | 中 | 多对多关系 |
| TransR | 关系特定空间 | 多 | 复杂关系 |
| TransD | 动态投影 | 中 | 自适应关系 |
| RotatE | 旋转操作 | 中 | 关系组合、逆关系、对称关系 |

## 三、双线性模型

### 3.1 DistMult（2015）

**核心思想**：用双线性打分，关系矩阵为对角矩阵。

```
评分函数：f(h, r, t) = h^T · diag(r) · t

即：f(h, r, t) = Σ h[i] · r[i] · t[i]
```

**优点**：简单高效
**缺点**：无法处理非对称关系

### 3.2 ComplEx（2016）

**核心思想**：在复数空间嵌入，处理非对称关系。

```
评分函数：f(h, r, t) = Re(h^T · diag(r) · t̄)

其中 t̄ 是 t 的共轭复数
```

### 3.3 HolE（2016）

**核心思想**：使用循环相关操作。

```
评分函数：f(h, r, t) = r^T · (h ⋆ t)
```

## 四、图神经网络模型

### 4.1 R-GCN（Relational GCN）

为知识图谱设计的关系感知图卷积网络。

```
h_i^(l+1) = σ(Σ Σ (1/c_i,r) · W_r^(l) · h_j^(l) + W_0^(l) · h_i^(l))
           r∈R j∈N_i^r

其中：
- R：所有关系类型
- N_i^r：实体 i 在关系 r 下的邻居
- W_r^(l)：关系 r 在第 l 层的权重矩阵
- c_i,r：归一化常数
```

### 4.2 CompGCN

组合图卷积，同时聚合实体和关系信息。

### 4.3 KGE + GNN 对比

| 类型 | 代表模型 | 特点 |
|------|---------|------|
| **浅层嵌入** | TransE, RotatE | 参数量小，训练快，但表达能力有限 |
| **GNN 方法** | R-GCN, CompGCN | 考虑邻居结构，表达能力强，但计算量大 |

## 五、知识推理

### 5.1 推理任务类型

| 任务 | 说明 | 示例 |
|------|------|------|
| **链接预测** | 预测缺失的实体或关系 | (?, 首都, 北京) → 中国 |
| **三元组分类** | 判断三元组是否成立 | (张三, 就职于, 阿里巴巴) → True/False |
| **关系推理** | 推导新关系 | A 是 B 的父亲，B 是 C 的父亲 → A 是 C 的祖父 |
| **实体类型推断** | 推断实体类别 | 能编程、写代码 → 程序员 |

### 5.2 基于嵌入的推理

利用向量运算进行推理：

```
链接预测：
  给定 (h, r, ?)，预测 t
  → 计算 score(h, r, t') 对所有候选 t'，取最高分

  给定 (?, r, t)，预测 h
  → 同理

关系预测：
  给定 (h, ?, t)，预测 r
```

### 5.3 基于规则的推理

```
规则示例：
  规则1：∀x,y,z (x, fatherOf, y) ∧ (y, fatherOf, z) → (x, grandfatherOf, z)
  规则2：∀x,y (x, marriedTo, y) → (y, marriedTo, x)
  规则3：∀x,y (x, bornIn, y) → (x, citizenOf, y)
```

**工具**：
- **AMIE+**：自动挖掘 Horn 规则
- **AnyBURL**：基于规则的快速推理
- **OWL 推理机**：支持 DL 推理

### 5.4 基于神经网络的推理

- **NTN（Neural Tensor Network）**：张量网络建模实体交互
- **ConvE**：卷积网络学习交互模式
- **ConvKB**：CNN 建模三元组

### 5.5 基于大模型的推理

大模型可作为通用推理引擎：

```
输入：
  已知：张三就职于阿里巴巴，阿里巴巴总部位于杭州
  问题：张三的工作地点在哪里？

LLM 推理：
  张三 → 就职于 → 阿里巴巴 → 总部位于 → 杭州
  ∴ 张三的工作地点是杭州
```

**优势**：
- 无需预定义规则
- 支持常识推理
- 灵活适应开放域

**劣势**：
- 可能出现幻觉
- 无法保证逻辑一致性
- 可解释性较弱

## 六、评估指标

### 6.1 链接预测指标

| 指标 | 说明 |
|------|------|
| **MRR**（Mean Reciprocal Rank） | 平均倒数排名，越高越好 |
| **Hits@N** | 正确答案排在前 N 的比例 |
| **MR**（Mean Rank） | 平均排名，越低越好 |
