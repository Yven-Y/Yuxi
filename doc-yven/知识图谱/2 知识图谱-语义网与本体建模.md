## 一、语义网（Semantic Web）概述

### 1.1 什么是语义网

语义网是 Tim Berners-Lee（万维网发明者）提出的下一代互联网愿景：

> "Web 上的数据不仅对人可读，也对机器可理解。"

核心思想：
- 给数据赋予明确的语义
- 机器能够自动理解、推理、整合信息

### 1.2 语义网技术栈

```
┌──────────────────────────────────────────┐
│  第7层：信任（Trust）                      │
│  数字签名、来源验证                        │
├──────────────────────────────────────────┤
│  第6层：逻辑（Logic）                      │
│  规则推理、逻辑证明                        │
├──────────────────────────────────────────┤
│  第5层：证明（Proof）                      │
│  推理链验证                               │
├──────────────────────────────────────────┤
│  第4层：本体（Ontology）                   │
│  OWL、RDFS：定义概念和关系                 │
├──────────────────────────────────────────┤
│  第3层：语义（Semantics）                  │
│  RDF：描述资源及其关系                     │
├──────────────────────────────────────────┤
│  第2层：语法（Syntax）                     │
│  XML、Turtle、JSON-LD                      │
├──────────────────────────────────────────┤
│  第1层：标识（Identity）                   │
│  URI/IRI：统一资源标识符                   │
├──────────────────────────────────────────┤
│  第0层：Unicode + URI                      │
└──────────────────────────────────────────┘
```

## 二、URI 与命名空间

### 2.1 URI（Uniform Resource Identifier）

唯一标识资源的字符串：

```
http://example.org/person/zhangsan
http://www.w3.org/1999/02/22-rdf-syntax-ns#type
```

### 2.2 命名空间（Namespace）

简化 URI 书写：

```turtle
@prefix ex: <http://example.org/> .
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .
@prefix owl: <http://www.w3.org/2002/07/owl#> .
@prefix foaf: <http://xmlns.com/foaf/0.1/> .
```

## 三、RDF（Resource Description Framework）

### 3.1 核心概念

RDF 是 W3C 标准的资源描述框架，基于**三元组**：

```
(Subject, Predicate, Object)
(主语, 谓语, 宾语)
```

### 3.2 示例

```turtle
@prefix ex: <http://example.org/> .
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .

ex:zhangsan rdf:type ex:Person .
ex:zhangsan ex:name "张三" .
ex:zhangsan ex:age 30 .
ex:zhangsan ex:worksAt ex:alibaba .

ex:alibaba rdf:type ex:Company .
ex:alibaba ex:name "阿里巴巴" .
ex:alibaba ex:location ex:hangzhou .
```

### 3.3 RDF 序列化格式

| 格式 | 特点 | 示例 |
|------|------|------|
| **RDF/XML** | XML 格式，机器友好 | `<rdf:Description>...</rdf:Description>` |
| **N-Triples** | 每行一个三元组 | `<s> <p> <o> .` |
| **Turtle** | 人类可读，支持缩写 | `@prefix ex: <...> .` |
| **JSON-LD** | JSON 格式，Web 友好 | `{"@context": ..., "@type": ...}` |
| **RDFa** | 嵌入 HTML | `<span property="...">` |

### 3.4 Turtle 语法详解

```turtle
@prefix ex: <http://example.org/> .

# 基本三元组
ex:zhangsan ex:name "张三" .

# 多条谓语缩写
ex:zhangsan ex:name "张三" ;
             ex:age 30 ;
             ex:worksAt ex:alibaba .

# 多个宾语
ex:alibaba ex:employee ex:zhangsan , ex:lisi , ex:wangwu .

# 空白节点
ex:zhangsan ex:address [ ex:city "杭州" ; ex:street "文一西路" ] .

# 数据类型
ex:zhangsan ex:birthDate "1990-01-01"^^xsd:date .
ex:zhangsan ex:salary "50000.00"^^xsd:decimal .

# 语言标签
ex:zhangsan ex:description "工程师"@zh , "Engineer"@en .
```

## 四、RDFS（RDF Schema）

RDFS 在 RDF 基础上增加了**模式层**，定义类和属性。

### 4.1 核心词汇

| 词汇 | 含义 | 示例 |
|------|------|------|
| `rdfs:Class` | 定义类 | ex:Person a rdfs:Class |
| `rdfs:subClassOf` | 子类关系 | ex:Student rdfs:subClassOf ex:Person |
| `rdf:Property` | 定义属性 | ex:worksAt a rdf:Property |
| `rdfs:subPropertyOf` | 子属性关系 | ex:manages rdfs:subPropertyOf ex:worksWith |
| `rdfs:domain` | 属性的定义域 | ex:worksAt rdfs:domain ex:Person |
| `rdfs:range` | 属性的值域 | ex:worksAt rdfs:range ex:Company |
| `rdfs:label` | 标签 | ex:Person rdfs:label "人"@zh |
| `rdfs:comment` | 注释 | ex:Person rdfs:comment "表示人类" |

### 4.2 示例

```turtle
@prefix ex: <http://example.org/> .
@prefix rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#> .
@prefix rdfs: <http://www.w3.org/2000/01/rdf-schema#> .

# 定义类
ex:Person a rdfs:Class ;
    rdfs:label "人"@zh ;
    rdfs:comment "表示人类个体" .

ex:Company a rdfs:Class ;
    rdfs:label "公司"@zh .

ex:Student a rdfs:Class ;
    rdfs:subClassOf ex:Person ;
    rdfs:label "学生"@zh .

# 定义属性
ex:worksAt a rdf:Property ;
    rdfs:domain ex:Person ;
    rdfs:range ex:Company ;
    rdfs:label "就职于"@zh .

ex:age a rdf:Property ;
    rdfs:domain ex:Person ;
    rdfs:range xsd:integer ;
    rdfs:label "年龄"@zh .
```

### 4.3 RDFS 推理示例

```
已知：
  ex:Student rdfs:subClassOf ex:Person .
  ex:zhangsan rdf:type ex:Student .

推理得出：
  ex:zhangsan rdf:type ex:Person .    （子类继承）

已知：
  ex:manages rdfs:subPropertyOf ex:worksWith .
  ex:zhangsan ex:manages ex:lisi .

推理得出：
  ex:zhangsan ex:worksWith ex:lisi .    （子属性继承）
```

## 五、OWL（Web Ontology Language）

OWL 是表达能力最强的语义网本体语言，支持复杂推理。

### 5.1 OWL 三个子语言

| 子语言 | 表达能力 | 推理复杂度 | 适用场景 |
|--------|---------|-----------|---------|
| **OWL Lite** | 最低 | 多项式时间 | 简单分类和约束 |
| **OWL DL** | 中（对应描述逻辑） | 可判定 | 需要完整推理能力 |
| **OWL Full** | 最高 | 不可判定 | 与 RDF 完全兼容 |

### 5.2 OWL 核心构造

#### 类定义

```owl
# 命名类
:Person a owl:Class .

# 类交集
:StudentWorker a owl:Class ;
    owl:intersectionOf (:Student :Worker) .

# 类并集
:ChildOrAdult a owl:Class ;
    owl:unionOf (:Child :Adult) .

# 类补集
:NonHuman a owl:Class ;
    owl:complementOf :Human .
```

#### 属性定义

```owl
# 对象属性（连接两个实例）
:worksAt a owl:ObjectProperty .

# 数据属性（连接字面量）
:hasAge a owl:DatatypeProperty .

# 属性特征
:marriedTo a owl:ObjectProperty ;
    owl:SymmetricProperty .    # 对称性：A marriedTo B → B marriedTo A

:hasParent a owl:ObjectProperty ;
    owl:InverseOf :hasChild .   # 逆属性

:isPartOf a owl:ObjectProperty ;
    owl:TransitiveProperty .    # 传递性：A partOf B, B partOf C → A partOf C

:hasSSN a owl:DatatypeProperty ;
    owl:FunctionalProperty .    # 函数性：一个实例只有一个值
```

#### 约束

```owl
# 基数约束
:Person a owl:Class ;
    rdfs:subClassOf [
        a owl:Restriction ;
        owl:onProperty :hasAge ;
        owl:cardinality 1        # 必须恰好有1个年龄
    ] .

# 全称量词
:Parent a owl:Class ;
    rdfs:subClassOf [
        a owl:Restriction ;
        owl:onProperty :hasChild ;
        owl:allValuesFrom :Person  # 孩子必须是人
    ] .

# 存在量词
:Parent a owl:Class ;
    rdfs:subClassOf [
        a owl:Restriction ;
        owl:onProperty :hasChild ;
        owl:someValuesFrom :Person  # 至少有1个孩子是人
    ] .
```

#### 等价与不相交

```owl
# 类等价
:Human owl:equivalentClass :Person .

# 实例等价
:zhangsan owl:sameAs :zhangsan_weibo .

# 类不相交
:Man owl:disjointWith :Woman .

# 不同实例
:zhangsan owl:differentFrom :lisi .
```

### 5.3 OWL 推理示例

```
已知：
  :hasParent owl:TransitiveProperty .
  :hasFather rdfs:subPropertyOf :hasParent .
  :zhangsan :hasFather :zhangfu .
  :zhangfu :hasFather :zhangye .

推理得出：
  :zhangsan :hasParent :zhangfu .
  :zhangfu :hasParent :zhangye .
  :zhangsan :hasParent :zhangye .    （传递性）

已知：
  :Person a owl:Class .
  :Student rdfs:subClassOf :Person .
  :Worker rdfs:subClassOf :Person .
  :StudentWorker owl:intersectionOf (:Student :Worker) .
  :zhangsan rdf:type :StudentWorker .

推理得出：
  :zhangsan rdf:type :Student .
  :zhangsan rdf:type :Worker .
  :zhangsan rdf:type :Person .
```

## 六、SPARQL 查询语言

SPARQL 是 RDF 的标准查询语言，类似 SQL。

### 6.1 基本查询

```sparql
# 查询所有人的名字
PREFIX ex: <http://example.org/>

SELECT ?name
WHERE {
  ?person rdf:type ex:Person .
  ?person ex:name ?name .
}

# 查询张三就职的公司
SELECT ?company
WHERE {
  ex:zhangsan ex:worksAt ?company .
}
```

### 6.2 高级查询

```sparql
# 多跳查询：张三的同事
SELECT ?colleague
WHERE {
  ex:zhangsan ex:worksAt ?company .
  ?colleague ex:worksAt ?company .
  FILTER (?colleague != ex:zhangsan)
}

# 可选模式
SELECT ?name ?age
WHERE {
  ?person ex:name ?name .
  OPTIONAL { ?person ex:age ?age }
}

# 聚合查询
SELECT ?company (COUNT(?person) AS ?count)
WHERE {
  ?person ex:worksAt ?company .
}
GROUP BY ?company

# 排序和限制
SELECT ?person ?age
WHERE {
  ?person ex:age ?age .
}
ORDER BY DESC(?age)
LIMIT 10
```

## 七、JSON-LD

JSON-LD 是 RDF 的 JSON 序列化格式，便于 Web 开发。

```json
{
  "@context": {
    "ex": "http://example.org/",
    "rdf": "http://www.w3.org/1999/02/22-rdf-syntax-ns#",
    "rdfs": "http://www.w3.org/2000/01/rdf-schema#"
  },
  "@id": "ex:zhangsan",
  "@type": "ex:Person",
  "ex:name": "张三",
  "ex:age": 30,
  "ex:worksAt": {
    "@id": "ex:alibaba",
    "@type": "ex:Company",
    "ex:name": "阿里巴巴"
  }
}
```

## 八、本体建模最佳实践

### 8.1 建模步骤

1. **需求分析**：明确领域范围和使用场景
2. **领域调研**：收集领域术语和概念
3. **本体设计**：定义类层次和属性
4. **形式化表达**：用 OWL/RDFS 描述
5. **实例填充**：添加具体实体数据
6. **验证推理**：检查一致性和完整性
7. **迭代优化**：根据反馈改进

### 8.2 设计原则

- **明确性**：术语定义清晰无歧义
- **一致性**：逻辑自洽，无矛盾
- **可扩展性**：预留扩展空间
- **最小本体**：只定义必要的概念
- **复用标准**：优先使用 FOAF、Schema.org 等公共本体

### 8.3 常用公共本体

| 本体 | 用途 | URI |
|------|------|-----|
| **FOAF** | 描述人及其关系 | http://xmlns.com/foaf/0.1/ |
| **Schema.org** | 通用 Web 数据标记 | https://schema.org/ |
| **Dublin Core** | 元数据描述 | http://purl.org/dc/elements/1.1/ |
| **SKOS** | 知识组织系统 | http://www.w3.org/2004/02/skos/core# |
| **DBpedia Ontology** | 通用知识 | http://dbpedia.org/ontology/ |
